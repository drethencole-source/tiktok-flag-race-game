سباق الأعلام V19 - النسخة العربية

الملفات:
- index.html : اللعبة باللغة العربية
- server.js : خادم Node.js و WebSocket
- package.json : الحزم المطلوبة

طريقة التشغيل:
1. ثبّت Node.js.
2. افتح Terminal داخل هذا المجلد.
3. شغّل: npm install
4. شغّل: npm start
5. للاختبار افتح: http://localhost:3000

قاعدة اللعبة:
كل هدية مقبولة = خطوة واحدة فقط.

عند رفعه على VPS سنضيف Nginx و HTTPS للحصول على رابط عام لاستخدامه في TikTok LIVE Studio.
